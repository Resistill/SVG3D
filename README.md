# SVG3D

SVG3D 是一种三维空间描述语言，面向 AI 的场景理解、逆向、编辑与风格化：用基本体、空间关系和布尔运算描述场景，而不是存一堆三角形。

这是从零重写的第二版。原型在同级目录 `../SVG3D`（冻结为 `prototype` 标签，只读）；新项目不继承原型的代码，继承的是语言、原则、测试语料与经验。

- 计划：[`docs/PLAN.md`](docs/PLAN.md)（第 9 节是里程碑与验收，第 10 节是已定的决定）
- 进度：[`docs/PROGRESS.md`](docs/PROGRESS.md)
- 当前阶段：M0（语言规范），`spec/` 的 10 章没写完不开 M1 的代码
- 约定：[`CLAUDE.md`](CLAUDE.md)

| 目录 | 内容 |
|---|---|
| `spec/` | 语言规范（Markdown）：语法、几何定义、求解语义、派生与层、事实、语义、元数据、兼容性、材质 |
| `crates/` | Rust 工作区：几何内核、编译器、评分、逆向、渲染、工程与意图、命令表、导出（M1 起建） |
| `web/` | 界面：TypeScript + Vite，薄；加载 wasm（M4 起建） |
| `corpus/` | 测试语料：示例、L0/L1/L2 导出、规则型意图样本、原型冻结前导出的参考输出包 |
| `docs/` | 计划、进度、原型的工具手册（作命令表迁移的参照） |
