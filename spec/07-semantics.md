# 7 语义层

**范围。** 本章定义语义层五种语句——concept、pattern、check、style、variant——的求值：两阶段求值的次序与保证（D9）、语义层的命名空间与可见性、语义层里可用的全部集合构件与关系谓词、`where` 字段在语义层的精确定义、每种语句的语义与输出形状、变体模板与外包络的接口、皮肤的不可见性与材质来源、style 与节点自身 `mat=` / `color=` 的优先级（D8）。本章同时定义只改外观的 `over` 与 style / variant 的等价关系。

本章**不**定义：语法与表达式文法（见 01-syntax.md）、实体与曲线的几何与包围盒（见 02-geometry.md）、定位与朝向的求解（见 03-solving.md）、over / drop 两个时机的判定与模板展开（见 04-derivation.md）、层的平铺顺序（见 05-layers.md）、空间事实的推导与关系索引（见 06-facts.md）、元数据的传播与输出（见 08-metadata.md）、材质解析的通用顺序（见 10-materials.md）。

**依赖的章。** 01（词法、语句形态、表达式、名字解析、选择器、`where` 字段的类型）、02（局部包围盒、紧包围盒）、03（世界变换、世界包围盒、容器的包围盒与包络、`at` / `pin`）、04（def 的展开、copy、副本与影子、over 的两个时机）、05（层的平铺顺序，即"后写"的含义）、06（事实、关系索引）、10（材质）。被依赖：04（外观时机 over 的效果）、05、09、10。
