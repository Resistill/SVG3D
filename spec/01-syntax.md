# 1 词法与语法、路径与命名、选择器

**范围。** 本章定义 `.s3d` 文件的词法（字符、记号、注释、字符串、数字、正则字面量）、语法（文件、语句、块、每种语句的形态，EBNF）、属性与类型（每种语句的合法属性表、字面量由类型决定）、表达式（文法、优先级、求值类型、内置函数、求值环境）、路径与命名（路径段的构造、名字解析顺序、歧义、保留名）、选择器与 `where`、`import` 的语法与路径解析、元数据的语法，以及诊断（报错的种类、携带的信息、错误恢复）。本章同时定义全规范统一的记法、规范用语、错误恢复原则与出错节点的退化处理（1.1 节），其他各章引用。

本章**不**定义：几何（实体与曲线的形状、包围盒、锚点的几何含义，见 02-geometry.md）、定位与朝向的求解（见 03-solving.md）、派生与修改的语义（def 的展开、copy、副本、over / drop 的两个时机的效果，见 04-derivation.md）、层的合并规则（见 05-layers.md）、空间事实（见 06-facts.md）、语义层的求值（concept / pattern / check / style / variant 的效果，见 07-semantics.md）、元数据的保证（见 08-metadata.md）、材质的解析顺序（见 10-materials.md）。本章对这些主题只给**语法**与**类型**，语义引用对应的章。

**依赖的章。** 无（本章是其他各章的基础）。被依赖：02 到 10 的每一章。

**记法。** 文法用 EBNF：`=` 定义，`|` 选择，`[ … ]` 可选，`{ … }` 零次或多次，`( … )` 分组，`"…"` 终结符，`?…?` 用文字描述的终结符。文法里的空白记号不写出；1.2 节规定哪些位置允许空白、哪些位置**不允许**空白（"紧跟"）。示例用 ```s3d 代码块；示例必须是本版合法的语句。

## 1.1 记法与规范用语

### 1.1.1 规范用语

- **必须 / 不得**：实现必须遵守；违反即不符合本规范。**应**：强烈建议，偏离要在实现文档里说明。**可以**：允许。
- **报错**（编译错误）：编译结果里记一条错误（1.10 节规定它携带的信息），编译按 1.1.4 的错误恢复规则继续；凡是本规范写"报错"的情况，实现**不得**静默接受。**警告**：记一条警告，不影响结果。
- "出错的语句"指触发报错的那条语句；"出错节点"指该语句本应生成的节点（1.1.4）。
- 未定义行为不存在：本规范没有定义的情况是规范的缺陷，实现遇到时**应**报错而不是猜测。

| 属性 property | `k=v`；元数据 metadata = `~k=v` |
| 块 block | `{ … }` 里的子语句 |
| 节点 node | 语句展开后场景树里的一个对象；路径 path = 从根到它的段序列，用 `.` 连接；名字 name = 最后一段（具名节点）|
| 实体 solid | 有体积的叶子：box、cyl、cone、sphere、wedge、hull、plate、revolve、span、sweep、pipe、mesh |
| 曲线 curve | arc、helix、line、bezier、spline；不是实体 |
| 容器 container | group、union、subtract、intersect、repeat、mirror / rotate 的容器式（以及它们的 copy）；union / subtract / intersect 是布尔容器。模板实例节点在定位与名字解析上按容器处理（03-solving.md 的 3.7、1.6.5） |
| 模板 template（类型） | `def` 定义的参数化类型；实例 instance；派生模板 `def B : A`；就地扩展 `def A : A` |

| 修改 modification | over / drop；两个时机：几何时机（求解前）、外观时机（求解后） |
| 层 layer | 被 import 的一个文件；几何层 / 外观层 |
| 语义层 | concept / pattern / check / style / variant |
| 空间事实 fact | 求解后推导出的关系；关系谓词 = 按事实筛选的函数 |

| 外包络 envelope | 容器声明的名义包围盒 |
| 包围盒 | 局部包围盒（节点自身坐标系的 AABB）、世界包围盒（局部包围盒变换后再取 AABB）、紧包围盒（按真实形状） |
| 变体皮肤 skin | variant 挂上的子树；原物体被隐藏 hidden |
| 场景单位 | 文件里数字的单位；`metre` 是内置常量 = 一米等于多少场景单位 |
| 词法环境 | let、模板参数、阵列索引、`it`、内置常量构成的名字表（1.5.8） |
| 退化节点 | 出错后按 1.1.4 处理的节点 |

### 1.1.3 坐标与数值

- 右手系，Y 向上。$+x$ = right / east，$-x$ = left / west；$+z$ = front / south，$-z$ = back / north；$+y$ = top / up，$-y$ = bottom / down。
- 实体的原点在其局部包围盒的底面中心（精确定义见 02-geometry.md 的 2.1.2 节）。
- 角度一律用度。旋转矩阵与合成顺序见 03-solving.md。向量是列向量，变换写成 $p' = R\,p + t$。
- 数值是 IEEE 754 双精度。表达式求值按本章 1.5 节；几何与求解的容差常数在用到的章给出并注明单位。
- 确定性：同一份输入在任何平台、任何线程数下必须得到逐位相同的结果。因此实现**必须**用同一套确定性的数学库实现 1.5.6 的函数（不得依赖平台 libm），凡是本规范里的"顺序"（节点顺序、集合顺序、错误顺序）都按本规范的定义，不得依赖哈希顺序或求和顺序。

### 1.1.4 错误恢复与退化节点

错误局部化原则：一条语句出错不得让无关的语句失效。具体规则：

1. **词法或语句形态错误**（1.10 节"语法错误"类：无法识别的字符、缺少结束引号、语句的形态不符合 1.3 节的文法、未知的种类词）：该语句**连同它的块**被丢弃，不生成节点；错误记一条；解析从下一条语句继续。被丢弃语句的名字在场景里不存在，引用它的地方按"找不到的名字"报错。
2. **属性错误**（种类不接受的属性、重复属性、类型错误、不合法的枚举值、缺少必填属性、同一语句里互斥的属性）与**求解错误**（找不到的名字、不唯一、循环依赖、几何参数不合法）：语句的节点照常创建并留在树里（路径、名字、标签、元数据、块都照常），但它成为**退化节点**：
   - 局部变换取恒等（$R = I$，$t = 0$，即放在父原点、不转）；局部包围盒与紧包围盒取零盒 $Z = [0,0]^3$；没有几何（不渲染、没有凸块）；
   - 不参与空间事实（06-facts.md）；可以被选择器选中，`where` 里 `w h d` 为 0、`x y z` 为它的世界原点、`top bottom` 为该原点的 y；
   - 它的子节点照常展开与求解（相对于它的局部系）；它参与父容器包围盒的并（以零盒计，02-geometry.md 的 2.6 节）；
   - 引用它的锚点得到零盒上的点（即它的原点），不再额外报错。
   一条语句上的多个属性错误各报一条，节点只退化一次。
3. **元数据错误**（1.9 节）：只影响该键（该键视为不存在），节点不退化。
4. **定义类语句**（def、let、material、concept、pattern、check、style、variant、import）出错：该语句不产生任何效果（def 不登记、concept 的成员为空集且输出带错误、style / variant 不作用、import 不导入），其他语句不受影响。
5. **修改类语句**（over、drop）出错：该语句不作用于任何节点。
6. 副本生成、变体挂载、材质解析等后续阶段的错误只影响出错的那个节点（或那一条语句），其他副本、变体、条目照常（原型里一个副本出错停掉全部后续副本、一个材质错误清空全部输出，本版不允许）。
7. 错误不中止编译：编译总是产出完整的结果（场景树、输出），错误列表与之并列。

### 1.1.5 错误的顺序

错误与警告各自按下列键升序排列：(1) 文件序号——主文件为 0，被 import 的文件按其 `import` 语句被处理的先后（深度优先）从 1 起编号，同一文件只有一个序号；(2) 行号；(3) 发现的先后。排序必须稳定。

## 1.2 词法

### 1.2.1 字符集与行

- 文件是 UTF-8 编码的文本；开头的 BOM（U+FEFF）忽略。无法解码的字节序列报错（语法错误），该行丢弃。
- 换行是 LF；CRLF 同样接受（CR 当空白）。行号从 1 起，按 LF 计数。
- 空白字符：空格（U+0020）、制表符（U+0009）、CR（U+000D）。其他 Unicode 空白不是空白（报"无法识别的字符"）。
- 字符按 Unicode 码点处理（不是 UTF-16 码元）；标识符不做规范化（NFC / NFD 不同的两个名字是不同的名字）。
- 词法分析逐字符进行，把源码切成**记号**（1.2.3–1.2.10）；记号之间可以有空白，除非规则写明"紧跟"（中间不得有任何空白或注释）。

### 1.2.2 注释、语句分隔与括号深度

- `//` 到行尾是注释；在字符串字面量与正则字面量内部的 `//` 不是注释。注释可以出现在任何允许空白的位置，包括括号内部（例如跨行的向量里）。没有块注释：`/*` 在表达式里是除号跟乘号，在别处是语法错误。
- **括号深度**：`(` 与 `[` 各使深度加一，`)` 与 `]` 使深度减一，且必须与同类的左括号配对（`(1]` 报错"括号不配对"）；深度为负（多余的右括号）报错，该记号丢弃。
- **换行**：深度为 0 的换行结束当前语句（产生记号 NL）；深度大于 0 的换行是空白。因此向量、列表、调用参数可以跨行；语句本身没有续行符。
- **分号** `;`：深度为 0 时是语句分隔符（等价于 NL；连续的 `;` 或空行等价于空语句，不报错）；在 `[ … ]` 内是列表分隔符（1.5.3）；在 `( … )` 内报错。
- **花括号** `{`、`}` 只能出现在深度 0；在括号内报错。`{` 开启块、`}` 结束块（1.3.2）。
- 文件末尾若没有换行，视为有一个 NL。

### 1.2.3 数字

```
number   = digits [ "." digits ] [ exponent ] | "." digits [ exponent ]
digits   = digit { digit }                        digit = "0" … "9"（只认 ASCII 数字）
exponent = ( "e" | "E" ) [ "+" | "-" ] digits
```

- 值按 IEEE 754 双精度最近舍入解析。前导零允许（`007` = 7）。`1.`（小数点后没有数字）、`1e`（指数没有数字）、`0x10`、`1_000` 都是语法错误。
- 数字记号后紧跟标识符字符（`1a`、`2metre`）是语法错误。
- **没有负数字面量**：`-3` 是一元负号作用于 `3`（1.5.2）。`3-1` 与 `3 -1` 都是减法；写向量 `(-60,240)` 或 `-60,240` 时负号是一元运算符。
- 路径里 `.` 后面的数字段（1.2.6）不是数字记号。

### 1.2.4 字符串

```
string = '"' { char | escape } '"'
escape = '\"' | '\\' | '\n'
```

- 只用双引号；`'`（单引号）在任何位置都是无法识别的字符。
- 转义只有三种：`\"` 双引号、`\\` 反斜杠、`\n` 换行。其他 `\x` 报错"未知的转义"。字符串里不得出现裸换行（报错"字符串缺少结束引号"，该语句丢弃，下一行从新语句开始）。
- 字符串内的 `//`、`#`、`~`、`{`、`;`、括号都是普通字符，不影响注释、深度与语句分隔。
- 两个相邻的字符串不拼接（报错"多余的内容"）。

### 1.2.5 标识符与关键字

```
ident       = ident_start { ident_char }
ident_start = ?Unicode 字母（General Category L*）? | "_"
ident_char  = ident_start | ?Unicode 十进制数字（Nd）?
```

- 大小写敏感。中文等任何 Unicode 字母可以做标识符（`房子`、`_x`、`a1`）。标识符不能含 `-`、`.`、`#`（`a-b` 是减法，`a.b` 是路径，`a#b` 是标识符后跟井号记号）。
- **关键字**（不能用作任何名字，在表达式里只按关键字解释）：`where and or not in true false`。
- 其他保留名（可以出现为标识符记号，但不能用作某些名字）见 1.6.9。

### 1.2.6 路径记号与方向组合词

路径是一个记号（中间不得有空白）：

```
path      = ident { "." segment }
segment   = ident | digits | "*"
```

- `.` 后面可以是标识符、纯数字（阵列实例段，1.6.2）或通配 `*`；首段必须是标识符。`a..b`、`a.`、`.a`、`a.-1` 都是语法错误；`*.b`（首段通配）是语法错误。
- **方向组合词**：方向词是 `top up bottom down left west right east front south back north center` 这 13 个标识符。一个方向词紧跟 `-` 紧跟另一个方向词（中间都没有空白）构成一个**方向组合词**，可以连接 2 到 3 个方向词；它是**一个**记号，作为一个路径段或一个独立的方向字面量：`top-left`、`B.top-left-front`、`pin=bottom-right`。规则：
  - 只有当 `-` 两侧**都是**方向词、且都紧跟时才合并；`x-1`、`w-left`、`B.top-foo`、`a-b`、`bridge-pier-deck` 都是减法（`bridge - pier - deck`）。
  - `top - bottom`（有空白）是减法。
  - 组合词里的方向词必须属于不同的轴（x 轴：left west right east；y 轴：top up bottom down；z 轴：front south back north）；`center` 不能出现在组合词里；违反的（`left-right`、`top-top`、`top-center`）报错"方向组合词矛盾"。
  - 组合词的值是各方向向量之和（1.6.8），与词序无关（`top-left` = `left-top`）。
- 路径记号后面**紧跟** `[` 时，`[ … ]` 是它的坐标后缀（1.5.4）；`B [1,2,3]`（有空白）是语法错误。坐标后缀的 `]` 后面紧跟 `.x`、`.y` 或 `.z` 时，它是分量后缀记号（`B[0.5].y`、`B.top[0,0].x`）；`]` 后面跟其他 `.…` 是语法错误。单段路径紧跟 `(` 是函数调用（1.5.6）；`sin (30)` 是语法错误；多段路径紧跟 `(` 报错"函数名不能带路径"。

### 1.2.7 井号记号

```
hash = "#" hash_name          hash_name = { ident_char }+     （"#" 与名字紧跟）
```

- `#` 后紧跟一个或多个标识符字符（字母、十进制数字、`_`），允许以数字开头（`#3`、`#1a`、`#cfe3f7`）。单独的 `#`、`#t-2`、`#x.y` 都是语法错误（`-`、`.` 不属于名字）。
- 井号记号的含义由位置决定（D5）：在语句的标签位置（1.3.3）是**标签声明**；在类型为"颜色"的属性值里是**颜色字面量**；在表达式里是**标签引用**（集合）。颜色字面量要求名字是 3、4、6 或 8 位十六进制数字（`0-9 a-f A-F`），否则报错"颜色写成 #rgb、#rgba、#rrggbb 或 #rrggbbaa"；颜色位置**不查标签**，标签位置与表达式位置**不判十六进制**（`#fff` 在选择器里就是标签 `fff`）。

### 1.2.8 运算符与分隔符

| 记号 | 用途 |
|---|---|
| `+ - * /` | 算术；`-` 也是集合差；`/` 也是正则字面量的定界符（1.2.9） |
| `== != < > <= >=` | 比较（都是单个记号，两侧不要求空白） |
| `~` | 正则匹配运算符；也是元数据前缀（1.2.10） |
| `\|` `&` | 集合并、交 |
| `,` | 向量分量、参数、面名列表的分隔 |
| `;` | 列表分隔（在 `[ ]` 内）；语句分隔（深度 0） |
| `.` | 路径段分隔（只在路径记号内部） |
| `=` | 属性赋值、let / concept 的定义 |
| `:` | over 的换形、def 的派生、concept 的上位 |
| `( ) [ ]` | 分组 / 调用、坐标后缀 / 列表 |
| `{ }` | 块 |
| `#` | 井号记号的前缀 |
| `*` | 乘法；路径里 `.` 后的通配段；pattern 角色名后的集合标记 |

其他任何字符（`'`、`!`（单独）、`%`、`^`、`@`、`$`、`\`（字符串外）、反引号、全角标点等）报错"无法识别的字符"，该语句丢弃。

### 1.2.9 正则字面量

```
regex = "/" { regex_char | "\/" } "/"
```

- 只在 `~` 运算符之后出现：当前一个记号是运算符 `~`（不是元数据前缀）时，接下来的 `/` 开始一个正则字面量，直到下一个未被 `\` 转义的 `/`；其中 `\/` 表示字面的 `/`。正则字面量里不得有裸换行。在其他位置 `/` 是除号。
- 正则语法是下面这个确定的子集（与 Rust `regex` crate 的语法一致，匹配不回溯、时间与模式和文本长度成线性）：

```
pattern     = alternation
alternation = concat { "|" concat }
concat      = { repetition }
repetition  = atom [ quantifier ]
quantifier  = "*" | "+" | "?" | "{" n "}" | "{" n "," "}" | "{" n "," m "}"      （贪婪；不支持 "?" 后缀的懒惰形式）
atom        = literal | "." | class | "^" | "$" | "\b" | "(" pattern ")" | "(?:" pattern ")" | class_escape
literal     = ?除 . ^ $ | ( ) [ ] { } * + ? \ / 以外的任何字符? | "\" ?上述任一元字符?
class       = "[" [ "^" ] { class_item } "]"       class_item = char | char "-" char | class_escape
class_escape = "\d" | "\D" | "\w" | "\W" | "\s" | "\S"
```

  - `.` 匹配除换行外的任意一个码点；`\d` = `0-9`，`\w` = 字母、数字、`_`（Unicode），`\s` = Unicode 空白；`^` / `$` 是文本开头 / 结尾；`\b` 是单词边界。没有反向引用、环视、命名组、标志（大小写敏感）。
  - 匹配语义是**搜索**：`s ~ /re/` 为真当且仅当 `re` 匹配 `s` 的某个子串；要整串匹配写 `^…$`。
  - 不符合上述语法的正则报错"正则不合法"（语法错误，整条语句丢弃）。

### 1.2.10 `~` 的两种用法

- `~` **紧跟**一个标识符字符时是**元数据前缀**：`~k=v`（1.9 节），只能出现在语句的属性区。
- 其他情况（后面是空白或 `/`）是正则匹配运算符 `~`，右操作数必须是正则字面量（1.5.5）。
- 所以 `name ~ /x/` 与 `name ~/x/` 都是匹配；`~src="a"` 是元数据。表达式里出现元数据前缀（`a ~k`）报错"元数据写成 ~名字=值，要写在属性之后"。

### 1.2.11 记号小结

记号种类：`NL`、`{`、`}`、数字、字符串、标识符（含关键字）、路径、方向组合词、井号记号、正则字面量、元数据前缀 `~k`、运算符与分隔符。词法分析不依赖语句种类；记号的含义（名字、标签、颜色、枚举值……）由 1.3 与 1.4 节按位置与类型决定。

## 1.3 语法

### 1.3.1 文件

```
file           = [ header ] { statement_line }
header         = meta { meta } NL
statement_line = [ statement ] NL
```

- **文件头**（D7）：文件里第一个非空、非注释的行若只由元数据项（1.9 节）组成，它是**文件元数据行**，不属于任何语句。其中键 `lang` 是本规范保留的唯一键：值必须是数字 `2`（缺省等价于 2；其他值报错"不支持的语言版本"，整个文件不编译）；它是声明，不切换语义。其他键不被规范解释，按 08-metadata.md 记录。文件头只能有一行；之后再出现只含元数据项的行报错"语句缺少种类词"。被 import 的文件可以有自己的文件头。
- 空语句（空行、只有注释的行、多余的 `;`）合法。
- 文件的全部语句处于**最外层**；块里的语句处于块内。1.3.15 规定每种语句允许的位置。

```s3d
~lang=2
// 一个最小的文件
box floor size=40,1,24 pin=top
```

### 1.3.2 语句与块

```
statement = generic | def | let | import | material | over | drop
          | concept | pattern | check | style | variant
block     = "{" { statement_line } "}"
```

- 一条语句从种类词开始，到深度 0 的 NL 结束；若 NL 之前的最后一个记号是 `{`，则该 `{` 开启这条语句的块，块到配对的 `}` 结束。`{` **必须与语句头在同一逻辑行**（`{` 单独起一行报错"`{` 前缺少语句"，该块到配对的 `}` 为止整体丢弃）。`}` 之后可以在同一行继续写语句（`group g { box a } box b`）。
- 块可以为空（`{ }`）。文件结束时块没有关闭：报错"缺少 }"（行号是 `{` 所在行），块内已解析的语句保留。多余的 `}` 报错并丢弃。
- 哪些语句接受块、块里允许什么，见 1.3.15。

### 1.3.3 通用形态：实体、曲线、容器、mesh、模板实例

```
generic   = kind_word [ name ] items [ block ]
kind_word = "box" | "wedge" | "plate" | "hull" | "mesh" | "cyl" | "cone" | "sphere" | "revolve"
          | "span" | "sweep" | "pipe" | "line" | "bezier" | "spline" | "arc" | "helix"
          | "group" | "union" | "subtract" | "intersect" | "repeat" | "mirror" | "rotate" | "copy"
          | template_name
name      = ident
items     = { tag | prop | meta }
tag       = hash
prop      = ident "=" value
meta      = "~" ident "=" value                      （"~" 与键紧跟，见 1.2.10）
value     = expression                               （1.5 节；解释由属性类型决定，1.4.2）
```

- **名字**是种类词之后的第一个记号，当且仅当它是一个标识符且后面不紧接 `=`。名字必须紧跟种类词：`box #t a`、`box size=1,1,1 a` 报错"名字要写在种类词之后"。名字可以省略（匿名节点，1.6.1）。名字不得是关键字；其他限制见 1.6.9。
- 名字之后，标签、属性、元数据的先后顺序任意。同一语句里同名属性重复、同名元数据键重复、同一标签重复都报错"重复的属性 / 元数据 / 标签"。
- 一个 `value` 从 `=` 之后开始，延伸到第一个不能继续该表达式的记号为止（1.5.1）；因此 `size=1,2,3 mat=steel` 里 `mat` 结束了 `size` 的值。值不能为空（`size=` 报错"表达式不完整"）。
- 种类词是模板名时是**模板实例语句**；模板名在展开时查找（04-derivation.md），既不是内置种类也不是已定义模板的种类词报错"未知的语句种类"。模板实例语句不接受块（带块报错）。
- `copy` 必须有名字与 `of=`，见 1.3.14。
- mirror / rotate 写了 `of=` 是副本式，不接受块；没写 `of=` 是容器式（块可以为空或省略）。

```s3d
box shelf size=10,9,2 on=floor align=back mat=c
subtract crate on=floor[0.55,1,0.4] mat=a {
  box shell size=5,4,5
  box hollow size=4.4,4,4.4 at=shell.bottom pin=bottom offset=0,0.3,0
}
cyl pole #post r=0.18 h=6 ~src="n1"     // 名字紧跟种类词；标签、属性、元数据顺序任意
house h4 floors=3 at=7,0,8              // 模板实例：参数与定位属性混写
```

### 1.3.4 def

```
def       = "def" ident [ "(" [ param { "," param } ] ")" ]
            [ ":" ident [ "(" [ override { "," override } ] ")" ] ]
            { meta } block
param     = ident [ "=" expression ]
override  = ident "=" expression
```

- 模板名、参数名都是标识符；记号之间可以有空白（`def house (w = 1, floors = 1)` 合法）。模板名不得是内置种类词或语句关键字（1.6.9；`def box` 报错"模板不能与内置种类同名"），不得是关键字。参数名不得是关键字，不得与定位 / 外观属性名（1.4.4 的 P 组与 `use`）同名（报错"参数名与属性名重名"），可以是 `w h d x y z`。同一签名里参数重名报错。
- 没有 `=` 的参数是必填参数；实例不给时报错"模板 X 缺少参数 p"（节点退化）。默认值是表达式，求值环境见 1.5.8。
- `: 基类型` 表示派生；`def A : A` 是就地扩展；覆盖表里的参数必须是基类型（或其派生链）已声明的，否则报错。语义见 04-derivation.md。
- 块必填（可以为空；没有块报错"def 需要块"，整条 def 无效）。块内允许的语句见 1.3.15。
- 元数据写在块之前。

```s3d
def truss(w=6, h=48, lv=8) ~src="lib" {
  repeat legs n=(2,1,2) step=w,0,w center=true { box leg size=0.6,h,0.6 }
}
def chimney_house : house(floors=2) { box chimney size=0.8,3,0.8 on=body[0.55,1,0.3] }
def tower : tower { box flag size=0.2,2,0.2 on=cap }
```

### 1.3.5 let

```
let = "let" ident "=" expression { meta }
```

- 名字不得是保留名（1.6.9；`w h d x y z` 允许）。`let` 可以写在任何块里；作用域与求值见 1.5.8。不接受块。

### 1.3.6 import

```
import = "import" string { meta }
```

- 只能写在最外层（块内、模板体内报错"import 只能写在最外层"）。路径解析见 1.8 节，语义见 05-layers.md。

### 1.3.7 material

```
material = "material" ident { prop | meta }
```

- 只能写在最外层（D6；块内报错"material 只能写在最外层"，该语句无效）。不接受标签、不接受块。属性表见 1.4.6；同名材质的覆盖规则见 10-materials.md。

### 1.3.8 over 与 drop

```
over = "over" selector [ ":" ident ] { prop | meta } [ block ]
drop = "drop" selector { meta }
```

- `selector` 是一个表达式（1.7 节），从种类词之后开始，到第一个不能继续它的记号为止：`:`、`k=`、`~k=`、`{`、NL 都结束选择器。选择器可以含空白（`over kind(box) where h > 1 size=2,2,2`）。选择器为空报错"over 需要选择器"。
- `: 种类` 是保名换形（04-derivation.md）；冒号两侧不要求空白（`over a: box` 与 `over a : box` 相同）；冒号后必须是一个标识符（内置种类词或模板名），否则报错"换类型写成 over 对象 : 类型"。`drop` 不接受冒号。
- 属性区之后不能再出现选择器片段（`over a size=1,1,1 b` 报错"属性之后不能再出现选择器"）。
- `over` 接受块（块内语句以被修改的节点为父，04-derivation.md）；`drop` 不接受块与属性。
- 哪些属性合法由被选中节点的种类决定（1.4.8）。两个时机的判定（几何 / 外观）见 04-derivation.md；本章只规定：选择器在几何时机只能用静态量（1.7.4）。

```s3d
over rocket.stage2 h=20
over tower lv=10 ~why="加层"
over hangar.roof use=ribbed
over kind(box) where name ~ /^tank/ : cyl r=1 h=3
drop lights.3
```

### 1.3.9 concept

```
concept = "concept" ident "=" expression { meta }
        | "concept" ident ":" ident "=" ( "where" or_expr | expression ) { meta }
```

- 只能写在最外层。名字不得是保留名、不得与 let / pattern 同名（1.6.9）。带 `: 上位` 时，`=` 右边若以 `where` 开头，整体是 `上位 where 条件`；否则是 `上位 & 表达式`（07-semantics.md）。不接受块。

```s3d
concept pier = kind(cyl) & on(river) & supports(kind(box))
concept column : member = where max(w,h,d) > 2.5 * metre and top - bottom > 0.95 * max(w,h,d)
concept platform : slab = (on(all()) | supports(all())) - terrain
```

### 1.3.10 pattern

```
pattern         = "pattern" ident "(" role { "," role } ")" { meta } "{" { constraint_line } "}"
role            = ident [ "*" ]
constraint_line = [ constraint ] NL
constraint      = role_in | relation | boolean
role_in         = ident "in" expression
relation        = expression relword expression
relword         = "on" | "supports" | "against" | "inside" | "contains" | "touching" | "intersects"
boolean         = expression
```

- 只能写在最外层。角色名是标识符，不得是保留名，同一签名里不得重复；至少一个角色；`*` 紧跟角色名表示集合角色。
- 块里每行一条约束，用 NL 或 `;` 分隔；注释允许；块里不得再出现 `{`、`}`。约束行按下面的顺序判定：
  1. 第一个记号是已声明的角色名且第二个记号是关键字 `in` → 角色域约束；`in` 后是任意集合表达式（可以含 `where`、可以引用前面声明的角色）。第一个记号是未声明的角色名 → 报错"X 不是这个 pattern 的角色"。
  2. 否则解析一个表达式；若其后的记号是关系词，再解析一个表达式 → 关系约束（两侧都是任意表达式）。
  3. 否则该行就是一个布尔约束。
- 元数据写在块之前。语义见 07-semantics.md。

```s3d
pattern crossing(deck, piers*, ramps*) {
  deck in kind(box)
  piers in pier
  ramps in kind(span)
  deck on piers
  ramps touching deck
  count(piers) >= 2
}
```

### 1.3.11 check

```
check = "check" [ string ] expression { meta }
```

- 只能写在最外层。说明是紧跟 `check` 的字符串字面量；之后的表达式必填（`check "只有说明"` 报错"check 写成：check "说明" 表达式"）。没有说明时，输出的 message 是表达式原文（从表达式第一个记号到最后一个记号的源码文本，首尾空白去掉）。不接受块。

### 1.3.12 style

```
style = "style" selector { prop | meta }
```

- 只能写在最外层。选择器是任意表达式（可以含空白），到第一个 `k=` 或 `~k=` 为止；至少一个属性；属性只能是 `mat`（材质名）与 `color`（颜色），各至多一次。不接受块。等价于只改外观的 `over 选择器 mat=… color=…`（07-semantics.md）。

```s3d
style railing | lamp mat=metal
style kind(cyl) & tree mat=wood
```

### 1.3.13 variant

```
variant = "variant" selector { prop | meta }
```

- 只能写在最外层。属性里必须有 `use`（模板名；缺省报错"variant 需要 use=模板名"）；其余属性是传给模板的参数（名字必须是该模板的参数，否则报错"模板 X 没有参数 k"）或 `mat` / `color`；`at`、`pin` 不接受（报错"变体的位置由外包络决定"，07-semantics.md）。不接受块。

### 1.3.14 copy

```
copy = "copy" ident items [ block ]
```

- 名字必填（报错"copy 需要名字"）；`of=` 必填（报错"copy 需要 of=原对象"），值是一个对象路径（不带坐标后缀、不是集合）。其他属性：定位 / 外观属性（1.4.4 的 P 组），以及原对象是模板实例时该模板的参数。块里允许 over、drop、let 与任何生成节点的语句（1.3.15）；语义见 04-derivation.md。

### 1.3.15 位置限制与块

| 语句 | 允许的位置 | 块 |
|---|---|---|
| 实体（box wedge plate hull mesh cyl cone sphere revolve span sweep pipe） | 最外层、任何块 | 不接受（带块报错"X 不能有子语句"，空块也报） |
| 曲线（line bezier spline arc helix） | 同上 | 不接受 |
| group / union / subtract / intersect | 同上 | 接受（可以为空） |
| repeat | 同上 | 接受（块是每个实例的内容；可以为空） |
| mirror / rotate 容器式 | 同上 | 接受（块是原件；可以为空或省略） |
| mirror / rotate 副本式（有 `of=`） | 同上 | 不接受（报错"写了 of= 就是复制已有对象，不能再有子语句"） |
| 模板实例 | 同上 | 不接受 |
| copy | 同上 | 接受 |
| over | 同上（块内的 over 只作用于该块的后代，04-derivation.md） | 接受 |
| drop | 同上 | 不接受 |
| let | 同上（作用域是所在块，1.5.8） | 不接受 |
| def、material、import、concept、pattern、check、style、variant | 只能最外层（块内、模板体内报错"X 只能写在最外层"） | def、pattern 必须有块；其余不接受 |

块内允许出现的语句 = 上表里"任何块"一列允许的语句：实体、曲线、容器、模板实例、copy、over、drop、let。模板体（def 的块）与 repeat 体、容器块、copy 块、over 块都按此表。

### 1.3.16 语句的行号与源文本

每条语句记录它的文件与首行行号；每个记号记录它所在的行。错误报告用出错记号所在的行（没有具体记号时用语句首行）。节点、concept、pattern、check、variant 的输出带它们的语句的文件与首行（具体字段由各章与输出格式定义）。

## 1.4 属性与类型

每个属性有**类型**（D24）。属性值先按 1.5 节的文法解析成表达式，再按类型解释：类型决定裸标识符是字面量还是名字、井号记号是颜色还是标签、值在什么时候求值。语句种类不接受的属性报错"X 没有属性 k"（D17），节点退化（1.1.4）。

### 1.4.1 类型表

| 类型 | 合法的值 | 不合法时 |
|---|---|---|
| 数 | 求值为有限双精度数的表达式 | 报错"`<路径>` 的 `<属性>` 需要数字"。取值范围（正数、整数等）由定义该属性的章规定 |
| 向量₂ | `a,b` 或 `(a,b)`，两个数 | 报错"…需要两个数" |
| 向量₃ | `x,y,z` 或 `(x,y,z)`，三个数；单个数 $v$ 展成 $(v,v,v)$ | 报错"…需要三维向量 x,y,z" |
| 向量₄ | `(x,y,z,deg)`，四个数 | 报错"…写成 (轴x,轴y,轴z,角度)" |
| 向量₆ | 六个数 | 各章给文案 |
| 点 | 向量₃；或对象引用（可带锚点、可加减向量₃，1.5.4）；集合（取其总包围盒中心，03-solving.md） | 报错"…需要点坐标或锚点" |
| 参照物 | 对象引用（可带锚点）；或非空集合 | 报错"…需要引用一个对象，得到 X"；空集合报错"集合是空的，不能当参照物" |
| 曲线 | 曲线节点（line bezier spline arc helix）的引用 | 报错"…需要一条曲线（line / bezier / spline / arc / helix）" |
| 点列表 | `[p; q; …]`，至少 1 项，每项是点 | 各章给文案 |
| 二元组列表 | `[(a,b); (c,d); …]`，至少 1 项 | 各章给文案 |
| 字符串 | 字符串字面量 | 报错"…需要字符串" |
| 颜色 | 井号记号，名字是 3 / 4 / 6 / 8 位十六进制（1.2.7） | 报错"颜色写成 #rgb、#rgba、#rrggbb 或 #rrggbbaa" |
| 材质名 | 名字字面量（1.4.2） | 材质不存在：报错"未定义的材质 X"（10-materials.md） |
| 模板名 | 名字字面量 | 报错"模板 X 没有定义" |
| 布尔 | `true` / `false` | 报错"…只能是 true / false" |
| 枚举⟨v₁ v₂ …⟩ | 名字字面量，取值限于列出的 | 报错"…只能是 v₁ / v₂ / …" |
| 方向 | 方向词或方向组合词（1.2.6） | 报错"…需要方向词，如 front / top-left" |
| 定位点 | `origin`；方向；向量₃（包围盒归一化坐标） | 报错"pin 写成 origin、方向词或 u,v,w" |
| 面名列表 | 一个或多个用 `,` 分隔的名字字面量，每个 ∈ {left right front back top bottom x y z} | 报错"align 只接受面名或 x / y / z，如 left,back" |
| 方向规格 | `x` / `y` / `z`；方向；向量₃；锚点引用（面锚点取其法线，曲线点取切线，03-solving.md） | 报错"…需要方向：x / y / z、方向词、向量，或锚点如 B.front" |
| 镜像面规格 | `x` / `y` / `z`；向量₃（面上的点）；参照物（可带锚点） | 报错"across 写成 x / y / z、点坐标，或对象 / 锚点（如 B、B.right、B.top）" |
| 轮廓 | `circle` / `rect`；二元组列表 | 报错"profile 只能是 circle / rect / 多边形列表" |
| 对象路径 | 单个对象的路径（不带坐标后缀、不是集合、不是锚点） | 报错"…写一个对象名" |
| 常量 | 在展开时求值的表达式：只能引用词法环境（let、参数、阵列索引、`metre`），不能引用对象；结果是数、向量、字符串、布尔或它们的列表 | 报错"…必须是常量" |
| 表达式 | 任何表达式（模板参数的值） | 由使用处的类型检查 |

### 1.4.2 值的解释规则

1. **名字字面量**：类型为材质名、模板名、枚举、方向、定位点、面名列表、方向规格、镜像面规格、轮廓的属性，值里的裸标识符（或方向组合词）按**字面**解释，不做名字查找（D4）。这些类型也接受内容相同的字符串字面量（`axis="y"`、`mat="steel"`），以便值经由 let 或模板参数传递。方向规格与镜像面规格有后备形式：裸标识符（或路径）不是 `x` / `y` / `z` / 方向词时，当作对象引用按 1.6.5 做名字查找。其余字面量类型（枚举、材质名、模板名、方向、定位点、面名列表、轮廓的 circle / rect）的值若不在允许集合里（也不是允许的向量形式），报错，不做名字查找。
2. **名字查找**：其余类型（数、向量、点、参照物、曲线、列表、常量、表达式）里的裸标识符按 1.6.5 的顺序解析为 let、参数、索引或对象；找不到报错"找不到对象 X"（D4）。
3. **井号记号**：颜色类型 → 颜色字面量；其他类型 → 标签引用（集合）。
4. **求值时机**：常量类型在展开时求值；元数据在展开时求值（1.9 节）；其余属性在求解时求值（03-solving.md），模板参数按惰性规则（1.5.8）。
5. **类型检查**在求值得到值之后进行：值的种类（1.5.7）不符合属性类型即报错，节点退化。

## 1.5 表达式

### 1.5.1 文法与优先级

```
value      = tuple                                   （属性值、元数据值、let / concept 的右侧、选择器、约束行都从这里开始）
tuple      = item { "," item }                       （≥ 2 项时是向量；1 项时就是该项）
item       = or_expr [ "where" or_expr ]             （where 不可链式：a where b where c 要加括号）
or_expr    = and_expr { ( "or" | "|" ) and_expr }    （左结合）
and_expr   = not_expr { ( "and" | "&" ) not_expr }   （左结合）
not_expr   = "not" not_expr | cmp_expr
cmp_expr   = sum [ cmp_op sum ] | sum "~" regex      （不结合：a < b < c 是语法错误）
cmp_op     = "==" | "!=" | "<" | ">" | "<=" | ">="
sum        = term { ( "+" | "-" ) term }             （左结合）
term       = unary { ( "*" | "/" ) unary }           （左结合）
unary      = "-" unary | primary
primary    = number | string | hash | "true" | "false"
           | call | path_ref | dir_word
           | "(" tuple ")"
           | "[" tuple { ";" tuple } "]"             （列表，至少 1 项；"[]"、"[a;]" 是语法错误）
call       = ident "(" [ item { "," item } ] ")"     （名字紧跟 "("；参数各是一个 item）
path_ref   = path [ "[" tuple "]" ] [ "." axis ]     （坐标后缀紧跟路径；见 1.5.4）
axis       = "x" | "y" | "z"
dir_word   = 方向组合词记号（1.2.6）
```

- 优先级从低到高：`where` < `or` `|` < `and` `&` < `not` < 比较与 `~` < `+ -` < `* /` < 一元 `-` < 基本项。`,`（向量）比 `where` 更低：`1, 2 where p` 是两项的向量，第二项是 `2 where p`；要写含逗号的 where 右侧请加括号。
- `A where P | B` 按上表解析为 `A where (P | B)`——`P | B` 对布尔与集合混用会报类型错误；要表示"筛选后再并"写 `(A where P) | B`。
- 关键字 `where and or not in` 只按关键字解释；出现在不允许的位置报错"关键字 X 用错了位置"。`true` / `false` 是布尔字面量。
- 没有一元 `+`（`+3` 报错）。
- **表达式的结束**：一个值从起点开始，延伸到第一个**不能继续**当前表达式的记号为止。能继续的记号是：二元运算符、`,`（在 tuple 层）、`;`（在列表内）、`where`、`and`、`or`、紧跟的 `[` 或 `(`、`.axis`。标识符、井号记号、字符串、数字、`:`、`{`、`}`、NL、`k=`、`~k=` 都不能继续一个已完整的表达式，所以它们结束表达式。表达式不完整（在需要操作数处遇到结束）报错"表达式不完整"。
- 整条值必须被耗尽：值之后紧接的记号由所在语句的文法处理（属性、标签、块…），文法不接受的记号报错"多余的内容"或语句自己的文案（1.3 节）。

### 1.5.2 算术与一元

| 运算 | 左 | 右 | 结果 |
|---|---|---|---|
| `+` | 数 | 数 | 数 |
| `+` | 向量 | 同长向量 | 向量（逐分量） |
| `+` | 引用 | 向量₃ | 带偏移的引用（偏移累加；偏移在被定位物体的父框架里，03-solving.md） |
| `-` | 数 | 数 | 数 |
| `-` | 向量 | 同长向量 | 向量 |
| `-` | 引用 | 向量₃ | 带偏移的引用 |
| `-` | 集合类 | 集合类 | 差集（1.5.5） |
| `*` | 数 | 数 | 数 |
| `*` | 向量 | 数 | 向量；`数 * 向量` 同 |
| `/` | 数 | 数 | 数；除数为 0 报错"除以零" |
| `/` | 向量 | 数 | 向量；除数为 0 报错 |
| 一元 `-` | — | 数 / 向量 | 取负 |

其他组合报错"无法计算 A op B"（错误文案里集合显示为 `{N 个对象}`、引用显示为路径、向量显示为 `(a,b,c)`）。结果必须是有限数；溢出到无穷或 NaN 报错"结果不是有限数"。

### 1.5.3 向量与列表

- 顶层逗号构成向量：`1,2,3` ≡ `(1,2,3)`；`(1)` ≡ `1`；`((1,2,3))` ≡ `(1,2,3)`。向量的分量必须是数（`(1,2),(3,4)`、`1,a`（a 是对象）报错"向量分量必须是数字，得到 X"）。向量长度由使用处的类型决定（向量₂ / ₃ / ₄ / ₆）。
- 列表 `[t₁; t₂; …]`：每项是一个 tuple（可以是向量、点、引用、集合…），至少 1 项；`[1;2;]`、`[]` 是语法错误。列表作为点列表 / 二元组列表时各项按对应类型检查；列表作为集合时各项先转成集合再并（1.5.5）。列表后面不能再跟后缀（`[1;2].x` 是语法错误）。

### 1.5.4 路径、锚点、坐标后缀、度量与分量

本节只定义语法与各写法指代什么；几何含义在 02-geometry.md（曲面锚点、曲线取点）与 03-solving.md（锚点、度量）。路径的解析（名字→节点）见 1.6.5。

| 写法 | 指代 | 要求 |
|---|---|---|
| `B` | 节点 B 的引用（没有锚点；作为点时取其中心，03-solving.md） | |
| `B.top`、`B.top-left-front`、`B.center` | 方向锚点（包围盒上的点与法线） | 最后一段是方向词或组合词 |
| `B.origin` | 原点锚点 | |
| `B[u,v,w]` | 包围盒归一化锚点（三个数，不限于 −1..1） | `[` 紧跟路径 |
| `C[t]` | 曲线 C 上按弧长参数 $t$ 的点（一个数） | C 必须是曲线，否则报错"X 不是曲线，不能用 [t] 取点" |
| `C.start`、`C.mid`、`C.end` | 曲线点 $t = 0, 0.5, 1$ | C 必须是曲线；不是曲线时这一段不是曲线点，按下文的后缀规则报错"P 中没有子对象或锚点 start" |
| `B.top[u,w]`、`B.side[θ,v]`、`B.surface[θ,φ]` | 曲面锚点（两个数） | 坐标必须恰好两个数，否则报错"曲面锚点写成 B.top[a,b]（两个数）"；种类限制见 02-geometry.md 的 2.4 节 |
| `B.w`、`B.h`、`B.d` | B 的局部包围盒尺寸（数） | |
| `B.x`、`B.y`、`B.z` | B 的中心在当前父框架里的分量（数） | |
| `锚点.x`、`锚点.y`、`锚点.z` | 任何上述锚点在当前父框架里的分量（数）；`B.top.y`、`B.start.x`、`B[0.5].y`、`B.top[0,0].x` 都合法 | |
| `a.*`、`a.*.b`、`a.*.*.b` | 通配集合：`*` 匹配该层全部子节点（含匿名、阵列实例、副本组、皮肤） | 通配路径后不能取锚点、度量或分量（报错"通配路径后面不能取锚点"） |
| `r.3`、`r.3.item` | 阵列实例段（1.6.2） | |

- 坐标后缀 `[ … ]` 里的数必须是 1、2 或 3 个：1 个是曲线参数，2 个只能跟在曲面名（`top side surface`）后面，3 个是归一化锚点；其他个数报错"锚点写成 名字[u,v,w]（包围盒内 -1..1），曲线上的点写成 名字[t]（0..1）"。
- 后缀段的判定顺序：路径先按 1.6.5 解析出最长的节点前缀 B；余下的段（restSegs）按上表解释：零段 → 引用；一段 `w h d` → 度量；一段 `x y z` → 分量；一段方向词 / 组合词 / `origin` → 锚点；一段 `start mid end`（B 是曲线）→ 曲线点；曲面名 + 两个坐标 → 曲面锚点；锚点 + `x y z` → 分量；其他组合报错"P 中没有子对象或锚点 X"。**后缀词永远按后缀解释**：路径下降时遇到 `w h d x y z start mid end top side surface origin` 与方向词 / 组合词就停止找子节点（1.6.5 第 5 步），所以 `B.top` 永远是锚点、`B.w` 永远是度量；碰巧叫这些名字的子节点（1.6.9 的软保留）不能作为后续段按名字引用（作为首段仍可，1.6.5 第 5 步）。
- `#tag.left`、`kind(box).w` 这类"集合取锚点"是语法错误；要先 `let walls = #wall` 再 `walls.top`（集合引用的锚点取总包围盒，03-solving.md）。

### 1.5.5 比较、逻辑、集合运算、where 与正则匹配

- `==` / `!=`：两边是同一种类的值时比较——数按数值；字符串（含名字）按码点；布尔；引用按节点同一性（锚点不参与）；向量逐分量；集合按成员集合（与顺序无关）。两边种类不同时 `==` 为假、`!=` 为真。**名字字面量规则**（D24）：左操作数是 where 字段 `kind`、`name` 或 `mat`（裸标识符）时，右操作数若是单段裸标识符则按名字字面量（字符串）解释，不做名字查找：`kind == box`、`name == a`、`mat == steel`；右侧也可以是字符串字面量。
- `< > <= >=`：两边必须是数，否则报错"op 两边需要数字，得到 A 和 B"。
- `~`：左边必须是字符串（`name`、`mat`、`kind`、字符串元数据、字符串字面量），右边必须是正则字面量；结果是布尔（搜索匹配，1.2.9）。左边不是字符串报错"~ 左边需要字符串"。
- `and` / `or` / `not`：操作数必须是布尔（集合、数、字符串都报错"需要真假值，得到 X"）；`and` / `or` 不短路（两边都求值；求值出错即报错）。
- `|` / `&` / `-`（集合）：操作数必须是**集合类**：集合、引用（→ 单元素集合；集合引用 → 其成员）、列表（各项转成集合后并）、模式值（→ 全部角色的并）。其他值报错"需要集合（对象、#标签、kind(…)、列表…），得到 X"。并、交、差都是数学集合运算；结果集合的顺序见下。
- **集合的顺序**：任何集合的成员顺序都是**节点顺序**（1.6.1）——`kind()`、`all()`、`#tag`、通配、列表、并交差、`where`、关系谓词、概念的结果都按节点顺序排列，与书写顺序、求值顺序无关。
- `S where P`：左边转成集合；对每个成员 $m$ 在 1.7.3 的 where 环境里求 $P$，必须得到布尔（否则报错"where 的条件需要真假值"），保留为真的成员。`where` 不能在展开时求值（元数据、常量里写 `where` 报错"where 只能在求解阶段使用"）。
- **缺失值**（1.7.3）：where 里读到节点没有的元数据键得到缺失值；任何比较、`~`、`and`、`or`、`not` 遇到缺失值结果为假（`not 缺失` 也为假，`缺失 != 1` 也为假）；算术与函数调用遇到缺失值结果为缺失；缺失值不能作集合、点或属性值（报错"元数据键 X 缺失"）。

### 1.5.6 内置函数

调用写 `名字(参数, …)`，名字紧跟 `(`。参数个数不符报错"X() 需要 N 个参数"；未知名字报错"未知函数 X()"。

| 函数 | 参数 | 结果 | 可用时机 |
|---|---|---|---|
| `sin cos tan` | 1 数（度） | 数 | 任何 |
| `asin acos atan` | 1 数 | 数（度） | 任何 |
| `atan2` | 2 数（y, x） | 数（度，$[-180, 180]$；$y$ 为负零、$x$ 为负时是 $-180$，与 libm 一致） | 任何 |
| `sqrt abs floor ceil` | 1 数 | 数 | 任何 |
| `round` | 1 数 | 数：四舍五入，恰好 .5 时远离零（$\mathrm{round}(2.5) = 3$，$\mathrm{round}(-2.5) = -3$） | 任何 |
| `pow` | 2 数 | 数 | 任何 |
| `min max` | ≥ 1 数 | 数 | 任何 |
| `count` | 1 集合类或模式值 | 数（成员数 / 匹配数）。参数既不是集合类也不是模式值报错"count() 需要集合或模式" | 展开时（常量、元数据）不可；几何时机的选择器及之后可——几何时机的选择器里参数只能由静态构件组成（1.7.4、05-layers.md 的 5.4.2），模式值要到语义层 |
| `all` | 0 | 全部节点的集合（不含皮肤、不含根；1.7.2） | 展开时（常量、元数据）不可；几何时机的选择器及之后可（按那一刻的树，5.4.2） |
| `kind` | ≥ 1 名字字面量或字符串 | 种类为其中之一的节点集合（1.6.7；模板实例按派生链；不含皮肤）。既不是内置种类词也不是任何已定义模板的名字得到空集并给警告"kind() 不认识 X" | 同 `all` |
| `children` | 1 集合类 | 各成员的直接子节点之并（含副本组、阵列实例；皮肤按 1.6.4） | 同 `all` |
| `descendants` | 1 集合类 | 各成员的全部后代之并（同上） | 同 `all` |
| `on supports against inside contains touching intersects` | 1 集合类 $S$，可选第 2 个数 $k$（默认 1） | 与 $S$ 里至少 $k$ 个成员有该关系的节点集合（06-facts.md 的 6.7、07-semantics.md 的 7.2.4）。$S$ 不是集合类报错"X() 需要参照集合，如 X(ground)"；$k$ 不是与某个整数 $m \ge 1$ 相差不超过 $\varepsilon_{\text{int}}$（03-solving.md 的 3.1.7）的数报错"X() 的第二个参数需要不小于 1 的整数" | 只在外观时机与语义层；几何时机的选择器、属性值与它们读到的 `let`（1.5.8）里报错"X() 依赖求解后的空间事实，不能用来决定位置 / 几何"；`factsSkipped` 时得到空集并警告（6.6.4、1.10.3） |

参数不是数的数学函数报错"X() 需要数字参数"；结果不是有限数（如 `sqrt(-1)`、`asin(2)`）报错"X() 的结果不是有限数"。所有数学函数必须用 1.1.3 要求的确定性实现。"可用时机"列里的"展开时"指常量与元数据的求值（1.4.2 第 4 条、1.9 节）：在那里调用集合函数是时机错误（1.10.2），文案按常量（1.4.1"…必须是常量"）与元数据（1.9 节）各自的规则；"几何时机的选择器"指 1.7.4。

### 1.5.7 值的种类与类型错误

| 种类 | 来源 |
|---|---|
| 数 | 数字字面量、算术、函数、度量与分量、`count` |
| 布尔 | `true` `false`、比较、逻辑 |
| 字符串 | 字符串字面量、名字字面量、where 的 `kind` `name` `mat`、字符串元数据 |
| 向量 | 逗号 / 括号向量；长度 2、3、4 或 6 |
| 列表 | `[ … ]` |
| 引用 | 路径解析得到的节点，带可选锚点与偏移；指向曲线节点的引用也用作"曲线" |
| 集合 | `#tag`、`kind()`、`all()`、通配、`children` / `descendants`、关系谓词、集合运算、`where`、概念名、集合值的 let |
| 模式值 | pattern 名；`模式.角色` 是集合 |
| 正则 | 只作 `~` 的右操作数 |
| 缺失 | 只来自 where 里不存在的元数据键 |

运算得到的值与属性类型不符时报错（1.4.2 第 5 条）。把集合当点用、把数当参照物用等都是类型错误，文案见 1.4.1。

### 1.5.8 求值环境

每个表达式在一个**上下文**里求值：上下文 = (词法环境 $E$，场景位置 $P$，时机)。$P$ 是一个容器节点（或根），叫**搜索起点**：对象名先在 $P$ 的子节点里找，再逐级向上（1.6.5）。"写在哪里就在哪里求值"（D26）的精确含义是：$E$ 与 $P$ 由**写下这个表达式的语句**决定，不随表达式被谁读取而变。

| 表达式写在 | $E$ | $P$ |
|---|---|---|
| 节点语句的属性值 | 该语句所在块的帧（模板体内是模板体帧） | 该节点的父节点（兄弟可见；自己的子节点不可见） |
| 块里的 `let` | 该块的帧 | 该块的节点（最外层为根） |
| 模板参数的默认值 | 模板体帧 | 实例节点的父节点 |
| 实例语句上写明的参数值 | 实例语句所在块的帧 | 实例节点的父节点 |
| `over` 的属性值 | 写 over 处的帧 | 被修改节点的父节点（成员是影子时按 04-derivation.md 的 4.4.4 的孪生体：原件的父节点） |
| `over` 块里的语句 | 块帧（含 `it`） | 被修改的节点 |
| `copy` 的属性值 | 写 copy 处的帧 | 拷贝节点的父节点 |
| `copy` 块里的语句 | 块帧（含 `it`） | 拷贝节点 |
| 被 copy 复制的语句 | **原语句的**词法环境：原语句所在块的帧、模板体帧（参数绑定取原件所属实例的）、阵列实例帧（`i j k idx` 取原件所属实例的） | **新位置**：拷贝节点的父节点（被复制语句自己的属性）/ 拷贝子树里对应的容器（块里的语句），所以 `on=legs` 在拷贝里绑定到拷贝自己的 `legs`（04-derivation.md 的 4.3.2 第 2–3 条） |
| 几何时机 over / drop 的选择器 | 写它处的帧 | 写它的块的节点（最外层为根） |
| 语义层语句（concept、pattern、check、style、variant、外观时机的 over）的选择器与表达式 | 语义帧 | 根 |
| `where` 谓词 | where 帧 | 外层的 $P$ 不变 |
| 元数据、常量 | 所在语句的帧 | 不查对象 |

**词法环境**是一条帧链，查名字从最内层帧向外：

| 帧 | 包含的名字 | 父帧 |
|---|---|---|
| where 帧 | 1.7.3 的字段、成员的元数据键 | 写 where 处的环境 |
| over / copy 块帧 | `it`；成员是阵列时另有 `i j k idx` | 写 over / copy 处的环境 |
| 阵列实例帧 | `i j k idx`（三维下标与扁平下标，03-solving.md） | repeat 语句所在的环境 |
| 块帧 | 该块里全部 `let` 的名字 | 外层块的帧 |
| 模板体帧 | 模板的全部参数（含派生链）、体内最外层的 `let` | **全局帧**（不是实例所在处的帧） |
| 全局帧 | 所有文件最外层的 `let`、内置常量 `metre` | 无 |
| 语义帧 | concept 名、pattern 名 | 全局帧 |

- 块内的 `let` 对整块可见，与书写顺序无关（可以前向引用）；同一块里同名 `let` 报错"重复定义 X"。最外层的 `let` 进全局帧，所有文件共享；最外层同名 `let` 后写的覆盖先写的（这是层的覆盖机制，05-layers.md），所有引用都用最终定义。
- `let` 是**惰性**的：第一次被读取时在它自己的上下文（上表第二行）里求值，并在同一时机内缓存（两个时机的缓存分开，05-layers.md 的 5.4.2 第 6 条）；求值中再次读到自己报错"X 循环引用了自己"。读取 `let` 的**时机与用途**决定它能用什么：
  - 被**几何时机 over / drop 的选择器**读到的 `let`：它的表达式视为该选择器的一部分，受 1.7.4 的限制——静态的 `where`（`kind`、`name`、`mat`、元数据键）、`all()`、`kind()`、`#tag`、通配、`children()` / `descendants()`、列表与集合运算可用；`w h d x y z top bottom`、锚点 / 度量 / 分量、关系谓词、概念 / 模式不可用。违反时报一条时机错误（1.7.4 的文案），**归属该 `let` 语句**，读它的 over / drop 整条无效、不另报（5.4.2 第 6 条）。
  - 被**属性值**（求解时求值）读到的 `let`，限制与属性值自己相同：可以引用对象、锚点、度量与分量；可以用 1.7.4 列出的静态集合构件——`#tag`、`kind()`、`all()`、`children()` / `descendants()`、通配、列表、集合运算、静态的 `where`（参照物与点可以是集合，03-solving.md 的 3.2.8）；不能用 `where` 里的 `w h d x y z top bottom` 与 `it` 的锚点 / 度量 / 分量、关系谓词、概念 / 模式（时机错误，报在读到它的地方，1.10.2；该节点退化）。
  - 被**常量 / 元数据**（展开时求值）读到的 `let`：按 1.4.1 的常量规则（只能引用词法环境；引用对象、`where`、集合函数都报错）。
  - 被**语义层与外观时机**读到的 `let`：没有限制，可以用全部字段、关系谓词、概念与模式。
  同一个 `let` 可以被不同时机读到；每次按读它的那个时机判定与缓存。
- 模板实例：模板体内语句的 $E$ 是模板体帧（看得见参数、体内 let、全局 let；看不见实例所在块的 let，也看不见实例所在阵列的 `i j k idx`）；体内语句的对象名从它们自己的父节点（实例节点或更深的容器）起向上找，所以同一模板放在不同位置可以绑定到不同的对象（D26）。参数的**默认值**在模板体帧里求值（可以引用其他参数与全局 let）；实例语句上**写明的参数值**在实例语句的上下文里求值（可用块内 let 与 `i j k idx`）。参数也是惰性的，循环报错。
- `it` 是 over 块、copy 块里的目标节点，where 谓词里的当前成员。
- `it` 只在 over 块、copy 块与 where 谓词里可见；`i j k idx` 只在 repeat 体（含其中的块与 let）、`over 阵列 { }` 块里可见；在别处使用报错"找不到对象 X"。
- `metre` 是全局帧里的数（宿主给出，默认 1）；不能被 `let` 覆盖（保留名）。
- 词法环境里的名字**遮蔽**同名对象（D26）：`let pad = 5` 后 `pad.top` 报错"pad 不是对象，不能取 .top"；模板参数 `blade` 遮蔽体内名为 `blade` 的节点（该节点仍可从外部按路径引用）。

## 1.6 路径与命名

### 1.6.1 节点、路径段与节点顺序

- 场景是一棵树；根不是节点（没有路径，错误文案里写作"场景"）。每个节点有一个**段**（segment）；路径 = 从根到该节点的段序列，输出时用 `.` 连接。段里不会出现 `.`。
- **具名段**：语句写了名字 → 段 = 名字。
- **匿名段**：语句没写名字 → 段 = `种类词#i`。种类词是该语句的第一个记号（内置种类词或模板名：匿名的 `house` 实例是 `house#3`，匿名 `repeat` 是 `repeat#6`，匿名 `mirror` 容器是 `mirror#7`）。$i$ 是**该父节点此前已创建的子节点总数**（从 0 起；按创建顺序计数，具名的也计，被 drop 的也计，永不回收、永不重排）。因此同一父节点下的匿名段两两不同，drop 与换形不会使编号碰撞；换形后的匿名节点保留原来的 $i$、换用新种类词。
- 匿名节点**不能被表达式寻址**（路径里写不出 `#`）；只能通过通配 `g.*`、`all()`、`children()` 选中，或经匿名容器穿透（1.6.5）引用它的子节点。
- **子节点顺序**（每个父节点的子节点列表）：
  1. 块里的语句按源码顺序生成子节点；模板体按派生链从基到派生依次展开（04-derivation.md），每个体内按源码顺序；
  2. `copy` 生成的节点占 copy 语句在其块里的位置；
  3. `over` 块里新增的节点追加在被修改节点现有子节点之后，多条 over 按应用顺序；
  4. 容器式 mirror / rotate 的副本组（1.6.3）排在容器全部原件之后，按 $k$ 递增；
  5. 变体皮肤 `skin`（1.6.4）排在被替换节点全部子节点之后；
  6. 保名换形后的节点保持原位置；drop 只删除，不移动其他节点。
- **节点顺序** = 从根开始的先序深度优先遍历（父在子前，子按上面的列表顺序）。D15 要求的"源码顺序的深度优先"即此；集合顺序、概念成员顺序、输出顺序都用它。

### 1.6.2 阵列实例段

`repeat` 节点的每个实例是它的一个子节点，段是十进制的扁平下标 `0`、`1`、…（$idx$，03-solving.md 定义 $idx$ 与 $(i,j,k)$ 的对应）。实例节点的种类是 `instance`（1.6.7），名字是该数字串。路径里数字段只能出现在非首段（`tanks.0.tank`、`row.3.item.p`）；`on=1` 是数，不是路径。实例节点不进全局索引（1.6.5），只能按路径引用。被 drop 的实例留下空洞，其余实例不重编号（`drop lights.3` 后剩 `lights.0 … lights.2`）。

### 1.6.3 副本段

- 容器式 `mirror … { … }`：原件留在容器下（段 = 自己的名字或匿名段）；副本是一个名为 `mirrored` 的组（种类 `mirror`，1.6.7），里面是原件的**影子**。容器式 `rotate … n=k`：$k$ 个副本组，段 `r1` … `rk`（种类 `rotate`）。
- 副本式 `mirror R of=A`、`rotate R of=A`：R 本身是节点（段 = R 的名字；种类 = A 的种类）；R 的子节点是 A 的子节点的影子。
- **影子**保留原件的段：具名的同名（`wings.mirrored.annex`、`rocket.fins.r1.fin`、`tower2.legs.0.leg`），匿名的按副本组自己的计数器重新编号（`mirror#0.mirrored.box#0`）。影子的种类、标签、元数据取自原件（1.6.7；语义见 04-derivation.md）。
- 副本组与影子不进全局索引；它们只能按路径引用（`on=wing2.body`、`rotor.r1.blade`）。

### 1.6.4 copy 段与变体皮肤段

- `copy R of=A`：生成的节点段 = R（名字必填），位置见 1.6.1。它是独立节点，进全局索引。
- 变体：被选中的节点 N 保留（隐藏），N 下挂一个段为 `skin` 的子节点（种类 = 变体模板名），皮肤模板体展开在它之下（`slab.skin.pl.0.plank`）。`skin` 子树不进全局索引、不进 `all()` / `kind()` / `#tag`，但进通配、`children()`、`descendants()` 与直接路径。这种"可见"只对两处有意义：**皮肤模板体内的表达式**（体内 over / drop 的选择器、`on=` 等属性，04-derivation.md 的 4.7 第 6 条）与**编译后的工具查询**；语义层与外观时机的全部选择器（concept、pattern、check、style、variant、外观时机的 over）都在皮肤生成之前求值，所以选不到皮肤（07-semantics.md 的 7.2.5 第 3 条）。皮肤对各种机制的可见与不可见的精确清单在 7.8.4。

### 1.6.5 名字解析

表达式里的裸标识符与路径的第一段按下面的顺序解析（D26）：

1. **词法环境**（1.5.8）：沿帧链从内到外找第一段；命中则该名字是变量：值是引用时，余下的段按 1.5.4 作为它的子节点路径或锚点后缀继续解析；值是集合时，余下的段只能是锚点 / 度量 / 分量（集合的锚点按总包围盒，03-solving.md），不能按名字进入成员（报错"{…} 中没有子对象或锚点 X"）；值是模式值时，余下一段是角色名（`home.roof`），其他报错"模式 X 没有角色 Y（有：…）"；其他值不能带后缀（报错"X 不是对象，不能取 .rest"）。
2. **场景树**：从该表达式的搜索起点 $P$（1.5.8）开始，依次在 $P$、$P$ 的父节点、……直到根的**子节点**里按下面的 `child(X, s)` 规则找第一段；第一个命中的层级即为所得，不再向上。
3. **全局索引**：第 2 步没有命中时，在全局索引里找第一段。全局索引 = 树里全部具名节点，**除去**阵列实例节点（数字段）、副本组、影子、`skin` 子树里的节点。恰好一个 → 用它；多于一个 → 报错"名字 X 不唯一，请写完整路径（p₁ / p₂ …）"（列出全部候选的路径，按节点顺序）；没有 → 报错"找不到对象 X"（D4）。
4. **where 里的元数据键**：只在 where 谓词里，且第 1–3 步都没有命中时，该裸标识符是元数据键的读取：成员有该键 → 键的值；没有 → 缺失值（1.5.5）。实现**应**在整个场景没有任何节点带该键时给出警告"没有节点带元数据 X"。
5. 第一段解析到节点 B 后，余下的段逐段下降：每段按 `child(当前节点, 段)` 找子节点（数字段匹配阵列实例，`*` 取全部子节点并把结果变成集合）；某段是后缀保留词（`w h d x y z start mid end top side surface origin`、方向词、方向组合词）或找不到子节点时停止下降，余下的段按 1.5.4 作为后缀解释；后缀不合法报错"P 中没有子对象或锚点 X"（P 是已解析到的节点的路径）。首段不受后缀保留词的限制（`on=back` 可以解析到名为 `back` 的节点）。

**`child(X, s)`**（在父节点 X 下按段 s 找子节点，带匿名容器穿透）：

- 候选 = **直接候选**加上**穿透候选**。直接候选：X 的具名子节点里段等于 s 的——有多个时（1.6.6 的同级重名在最终的树上判定之前，阶段 5 的树里它们可以并存，04-derivation.md 的 4.1.1；也包括 `drop pad` 之后再 `box pad` 的写法，05-layers.md 的 5.3.2）只算**节点顺序最先**的那一个（与 1.6.6"引用该名字得到先出现的节点"一致），不算"不唯一"。穿透候选：对 X 的每个**匿名的非叶子**子节点——没有名字的 group / union / subtract / intersect / repeat、容器式与副本式的 mirror / rotate、模板实例——递归应用 `child` 得到的（匿名实体与曲线没有子节点，不涉及）。阵列实例、副本组、皮肤有段名，不被穿透（匿名 `repeat` 里的 `box leg` 从外面按 `leg` 找不到：实例段 `0`、`1` 挡住了穿透，于是落到全局索引，若两个实例都有 `leg` 则报"不唯一"）。
- 候选恰好一个 → 命中；多于一个（只可能是穿透候选之间、或直接候选与穿透候选之间）→ 报错"名字 X 不唯一，请写完整路径（…）"；没有 → 未命中。
- 穿透只在按名字找子节点时发生；通配 `*` 不穿透（只取直接子节点）。

```s3d
group { group { box deep size=1,1,1 } }
box b size=1,1,1 on=deep        // 穿透两层匿名 group
```

### 1.6.6 同级重名与 import 后的重名

- **同一父节点下的两个具名子节点段相同**报错"同级重名 X"（D18），报在后出现的语句上，后出现的语句（连同块）不生成节点；引用该名字得到先出现的节点。判定在 copy、副本、皮肤都生成之后对整棵树做一次；副本组、影子、皮肤的段与用户名字冲突时同样报错（所以 1.6.9 把 `mirrored`、`skin` 列为保留名，`r` + 数字不能作 rotate 容器的直接子节点名）。
- 被 import 的文件的最外层语句与主文件的最外层语句在同一个根下，所以跨文件的同名节点也是同级重名；同一文件被第二次 import 时报错且不导入（D19，05-layers.md），因此不会由此产生重名。`def`、`material`、`concept`、`let` 等**定义**的同名覆盖规则不属于本节（05-layers.md、1.5.8）。

### 1.6.7 `kind`、`name`、标签的取值

| 节点 | `kind`（种类） | `name` |
|---|---|---|
| 实体、曲线、group / union / subtract / intersect / repeat、容器式 mirror / rotate | 语句的种类词 | 名字；匿名为空串 `""` |
| 模板实例 | 最派生的模板名；`kind(T)` 对派生链上的每个 T 都为真 | 名字 |
| 阵列实例 | `instance` | 下标的数字串 |
| 副本组 `mirrored` / `r<k>` | `mirror` / `rotate` | `mirrored` / `r<k>` |
| 副本式 `mirror R of=A` / `rotate R of=A` | A 的种类（含派生链） | R |
| 影子 | 原件的种类（含派生链） | 原件的名字 |
| copy 节点 | 原件语句的种类（含派生链） | copy 的名字 |
| 变体皮肤 `skin` | 变体模板名（含派生链） | `skin` |
| 保名换形后的节点 | 新种类 | 不变 |

- `kind(a, b, …)` 选中种类（或派生链）属于参数之一的节点；参数是内置种类词或模板名（名字字面量或字符串），不认识的名字得到空集，不报错。`kind(group)` 只选 `group` 语句生成的节点；`kind(instance)` 选阵列实例；`kind(mirror)` 选容器式 mirror 节点与它们的副本组。
- `where` 里的 `kind` 是上表的种类名（字符串），`name` 是上表的名字。
- **标签**：节点的标签集合 = 语句上声明的 `#tag`。影子与副本式节点 R 的标签 = 原件的标签（R 自己写的 `#tag` 再并上）；copy 节点 = 原件语句的标签 ∪ copy 语句的标签；阵列实例、副本组没有标签（repeat / mirror / rotate 节点自己有）；皮肤子树里的节点各自按其语句（皮肤节点本身没有）。`#tag` 表达式 = 标签集合含 tag 的全部节点（不含皮肤）。

### 1.6.8 方向词表

| 方向词 | 向量 |
|---|---|
| `top` `up` | $(0, 1, 0)$ |
| `bottom` `down` | $(0, -1, 0)$ |
| `right` `east` | $(1, 0, 0)$ |
| `left` `west` | $(-1, 0, 0)$ |
| `front` `south` | $(0, 0, 1)$ |
| `back` `north` | $(0, 0, -1)$ |
| `center` | $(0, 0, 0)$ |

组合词的向量 = 各词向量之和（`top-left-front` = $(-1, 1, 1)$）。锚点、法线、`align` 对这些向量的使用见 03-solving.md（`align` 只接受单个面名与 `x y z`，1.4.1）。

### 1.6.9 保留标识符

保留名分两类：**硬保留**——用作名字即报错"X 是保留名，不能用作 …"，该语句按 1.1.4 第 1 条丢弃（def、let、concept、pattern 整条无效）；**软保留**——只对节点名放行并给警告。软保留又分两组，警告文案不同：

- **后缀保留词**（方向词、`w h d x y z`、`start mid end side surface origin`）：警告"节点名 X 与保留名相同，作为路径的后续段时不能按名字引用"，因为路径后缀里这些词永远按保留含义解释（1.5.4、1.6.5 第 5 步：`B.top` 永远是锚点、`B.w` 永远是度量）。这样的节点作为路径**首段**仍可引用（首段不受后缀保留词的限制——`on=back` 照常解析），作为**后续段**（`bench.back`、`g.w`）不能按名字到达，只能被通配、`all()`、`#tag`、`kind()`、`children()` 选中。
- **其他软保留名**（语句种类词、内置函数名与常量、关系词）：警告"节点名 X 与保留名相同"。它们不是后缀保留词，作为后续段仍可按名字到达（`g.floor` 解析到名为 `floor` 的子节点；`floor(…)` 紧跟 `(` 才是函数调用，1.2.6），警告只提示可读性。

语料命中两处：basics.s3d:8 的 `box floor`（`floor` 是内置函数名，第二组）与 curves.s3d:54 的 `box back`（方向词，第一组），各一条警告（corpus/exports 里对应的 basics.L0.s3d:8、curves.L0.s3d:38 同样）；basics.s3d 里 6 处 `on=floor…` 都是首段引用，照常解析（09-compat.md 的 9.3.4）。

| 组 | 名字 | 节点名 | 模板名 | let 名、参数名 | 概念名、模式名、角色名 |
|---|---|---|---|---|---|
| 关键字 | `where and or not in true false` | 硬 | 硬 | 硬 | 硬 |
| 语句种类词 | `box wedge plate hull mesh cyl cone sphere revolve span sweep pipe line bezier spline arc helix group union subtract intersect repeat mirror rotate copy def let import material over drop concept pattern check style variant` | 软 | 硬 | 硬 | 硬 |
| 方向词 | `top up bottom down left west right east front south back north center` | 软 | 硬 | 硬 | 硬 |
| 度量词与坐标轴 | `w h d x y z` | 软 | 硬 | **允许** | 硬 |
| 曲线点、曲面、原点 | `start mid end side surface origin` | 软 | 硬 | 硬 | 硬 |
| where 字段、块内自指、阵列索引 | `it kind name mat idx i j k` | 硬 | 硬 | 硬 | 硬 |
| 内置函数与常量 | `all count children descendants sin cos tan asin acos atan atan2 sqrt abs min max floor ceil round pow metre` 及关系词 `on supports against inside contains touching intersects` | 软 | 硬 | 硬 | 硬 |
| 生成的段名 | `mirrored skin`；`r` 后跟 1 个或多个十进制数字（`r1` `r25`）只对 rotate 容器的直接子节点 | 硬 | 硬 | 硬 | 硬 |
| 内部种类名 | `instance` | 硬 | 硬 | 硬 | 硬 |

- 软保留对节点名放行是为了兼容已有语料（例如长椅的 `box back`）；新写的文件**应**避免。
- 属性名（`size`、`gap`、`of` …）与材质名不在此表：节点可以叫 `r`、`gap`，材质可以叫 `top`；材质名只需不是关键字。模板名可以与节点名相同（它们出现在不同位置）。
- 概念名、模式名、最外层 let 名三者共用语义帧与全局帧的查找链（1.5.8）：概念 / 模式与最外层 let 同名报错"X 已定义为 let / concept / pattern"；概念与模式同名报错。

### 1.6.10 路径的比较与输出

路径按**段序列**比较：两条路径相等当且仅当段数相同且逐段相同（字符串按码点）。输出里路径写成段用 `.` 连接的字符串；因为段不含 `.`，这个字符串与段序列一一对应。集合、事实、概念成员等输出里的节点一律用路径标识。

## 1.7 选择器与 where

### 1.7.1 选择器的文法

选择器就是一个求值为集合类的表达式（1.5 节）；没有单独的文法。能写的形式：

| 形式 | 含义 |
|---|---|
| 路径 `a.b.c` | 单个节点（引用 → 单元素集合）；可经阵列段、副本段、`skin` |
| 通配 `a.*`、`a.*.b` | 1.5.4 |
| `#tag` | 带该标签的节点（不含皮肤） |
| `kind(a, b)` | 1.6.7 |
| `all()` | 1.7.2 |
| `children(S)`、`descendants(S)` | 1.5.6 |
| `[a; b; …]` | 列表 → 各项转集合后并 |
| `S | T`、`S & T`、`S - T` | 并、交、差 |
| `S where P` | 筛选 |
| 概念名、`模式名`、`模式名.角色` | 只在语义层与外观时机（07-semantics.md） |
| `on(S)` 等关系谓词 | 只在语义层与外观时机 |

over / drop 的选择器从种类词之后开始，到 `:`、`k=`、`~k=`、`{` 或 NL 为止；style / variant 的选择器到第一个 `k=` / `~k=` 为止；concept 的选择器是 `=` 右边的全部。选择器求值为空集时：over / drop 报错"X 没有选中任何对象"，该语句无效——这对**两个时机**都成立：几何时机的 over / drop（含推迟到阶段 6 再求一次仍为空的，04-derivation.md 的 4.4.4），以及外观时机的 over（它被登记为一条 style 或 variant，4.5.1，但空选择仍按 over 报错，05-layers.md 的 5.4.2 第 7 条、07-semantics.md 的 7.7.4）；style / variant / concept / check 不报错（空集合法）。

### 1.7.2 `all()` 与可见范围

`all()` 是**除皮肤子树与根之外**的全部节点：实体、曲线、容器、阵列节点与实例、模板实例、副本组、影子、副本式节点、copy 节点、被变体隐藏的原物体、退化节点。`kind()`、`#tag` 的范围与此相同。通配、`children()`、`descendants()`、直接路径还能看到皮肤子树（1.6.4）——但只在皮肤模板体内的表达式（04-derivation.md 的 4.7 第 6 条）与编译后的工具查询里有意义：语义层与外观时机的选择器都在皮肤生成之前求值（07-semantics.md 的 7.2.5 第 3 条），它们的选择集不可能含皮肤节点。皮肤的可见与不可见的精确清单见 7.8.4。

### 1.7.3 where 可读的字段

`S where P` 对每个成员 $m$ 建立 where 帧，里面的名字按下表取值（where 帧是最内层帧，所以这些字段遮蔽同名的元数据键、let、参数与对象）。几何量的精确定义引用 03-solving.md 与 07-semantics.md（世界量）。

| 字段 | 类型 | 定义 |
|---|---|---|
| `w` `h` `d` | 数 | $m$ 的局部包围盒沿局部 $x, y, z$ 的边长（02-geometry.md 2.1.3；有 envelope 的 group 用 envelope） |
| `x` `y` `z` | 数 | $m$ 的世界包围盒中心的世界坐标 |
| `top` `bottom` | 数 | $m$ 在世界里占据的 $y$ 范围的上端 / 下端：实体按紧包围盒（真实形状），其他节点按世界包围盒（07-semantics.md） |
| `kind` | 字符串 | 1.6.7 的种类名 |
| `name` | 字符串 | 1.6.7 的名字 |
| `mat` | 字符串或缺失 | $m$ 的有效材质名 $E_g$（10-materials.md 的 10.5.3：自有属性与继承，不含 style；几何时机按那一刻的自有外观属性，外观时机与语义层按最终的）；没有任何材质时为缺失值 |
| `it` | 引用 | $m$ 本身（可取锚点：`it.top.y`） |
| 元数据键 | 元数据值或缺失 | $m$ 的元数据（影子取原件的；1.9 节）；按 1.6.5 第 4 步读取 |

- 新谓词（D3）：`name ~ /正则/`、`<元数据键> ~ /正则/`、`mat == 材质名`、`mat ~ /正则/`、`kind ~ /正则/`。
- 退化节点（1.1.4）的 `w h d` 为 0。
- `where` 里读 `w h d x y z top bottom`（以及 `it` 的锚点 / 度量 / 分量）要求成员已求解，所以只能在求解之后的时机使用（1.7.4）；`kind`、`name`、`mat`、元数据键与只作集合 / 引用比较的 `it` 是静态量，两个时机都可以（`mat` 在几何时机按那一刻的自有外观属性求，10-materials.md 的 10.5.3）。

```s3d
concept tank = kind(cyl) where w > 2.5 * metre and h > 2.5 * metre
check "导入的部件都有来源" all() where name ~ /^merged_/ and not (src ~ /./)
style all() where mat == concrete color=#e8f1fb
```

### 1.7.4 两个时机的选择器限制

几何时机（求解前生效的 over / drop，04-derivation.md）的选择器只能用**静态量**（D10）：路径、通配、`#tag`、`kind()`、`all()`、`children()`、`descendants()`、列表、集合运算、`count()`（参数由这些静态构件组成），以及 `where` 里的 `kind`、`name`、`mat`、元数据键、只用于取路径 / 名字 / 种类或作集合与引用比较的 `it`。在几何时机的选择器里读 `w h d x y z top bottom`、取任何对象的锚点 / 度量 / 分量、引用概念 / 模式，都报错"几何时机的选择器只能用静态量（路径、#标签、kind()、name / 元数据 / mat）"；调用关系谓词报错"X() 依赖求解后的空间事实，不能用来决定位置 / 几何"（1.5.6）。判定是静态的（在求值前对表达式树检查，不依赖成员集合）；选择器读到的 `let` 的表达式视为选择器的一部分，错误归属该 `let` 语句（1.5.8）；逐构件的表、检查顺序与原型的差别见 05-layers.md 的 5.4.2。外观时机的 over、style、variant、concept、pattern、check 的选择器可以用全部字段、关系谓词、概念与模式（D12）。

## 1.8 import 的语法与路径解析

```
import = "import" string { meta }
```

- 只能写在被编译文件（主文件或被 import 的文件）的最外层。语义（展开顺序、覆盖规则、层）见 05-layers.md；本节只定义路径解析与错误。
- **路径解析**：字符串是路径；分隔符只认 `/`（`\` 报错"import 路径用 / 分隔"）。以 `/` 开头、或以 `字母:/` 开头的是绝对路径；否则相对于**写这条 import 的文件所在目录**。该目录先由宿主换成**绝对路径**（主文件的路径由宿主给出；没有路径时用宿主的当前目录），再与字符串拼接并规范化：按 `/` 切段，丢弃空段与 `.`，`..` 弹出前一段（已到文件系统的根、没有段可弹时报错"import 路径越出根目录"），再连接；最后由宿主做规范化（解析符号链接与大小写由宿主决定，但同一文件必须得到同一个规范路径）。先绝对化再规范化，所以 `../lib/semantics.s3d` 这类以 `..` 开头的相对路径合法，不取决于宿主给主文件的是相对路径还是绝对路径；只有越出文件系统的根才报错。
- 规范化后的绝对路径是文件的**身份**：与主文件相同、或已被 import 过的文件再次 import 报错"文件 X 已经 import 过"（D19，不做 include-once）；正在加载链上的文件再次出现报错"import 形成了循环：a → b → a"（链包含主文件）。两种错误都不导入。
- 文件不存在或不能读报错"import 找不到文件 X"（X 是规范化路径）。
- 被 import 的文件独立做词法与语法分析（自己的行号、自己的文件头）；其错误带该文件的路径；文件序号按 1.1.5。
- 同一主文件的编译里，错误与节点输出的 `file` 字段用宿主给出的可显示路径（通常是相对主文件目录的路径），文件身份用规范化绝对路径；两者的对应由宿主维护。

```s3d
import "spaceport.s3d"
import "../lib/semantics.s3d" ~layer="semantics"
```

## 1.9 元数据的语法

```
meta = "~" ident "=" value       （"~" 紧跟键；键是标识符，不得是关键字）
```

- 元数据对**所有语句**合法（D2）：实体、曲线、容器、模板实例、copy、mirror / rotate、def、let、import、material、over、drop、concept、pattern、check、style、variant，以及文件头（1.3.1）。写在语句的属性区（名字之后、块之前），与属性、标签的先后任意。
- **值**是常量（1.4.1）：在展开时、在写它的语句的词法环境里求值，可以引用 let、模板参数、`i j k idx`、`metre`，不能引用对象（报错"元数据不能引用对象 X"）、不能用 `where` / `all()` / 关系谓词。结果必须是数、字符串、布尔、向量，或由这些组成的列表；其他值报错"元数据的值只能是数、字符串、布尔、向量或它们的列表"。井号记号在元数据值里是**标签引用**（不是颜色），因而是对象引用 → 报错；要存颜色写字符串 `"#abc"`。
- 同一语句里同一键出现两次报错"重复的元数据 k"。键不能是关键字；可以与属性名、保留名相同（`~kind=1` 合法，但 where 里 `kind` 读的是字段，1.7.3）。
- 元数据求值出错时该键不存在（节点不退化，1.1.4）。
- 元数据不参与几何、求解、事实、材质；可以在 `where` 里读（1.7.3）；传播规则（副本、copy、皮肤、换形）与输出见 08-metadata.md。
- 规范不保留任何键名，`lang` 只在文件头有意义（1.3.1）。

```s3d
box floor size=40,1,24 at=0,-1,0 mat=a ~fit=1 ~src="floor"
over tower lv=10 ~reason="加高"
let n_piers = 4 ~unit="count"
```

## 1.10 诊断

### 1.10.1 错误携带的信息

每条错误（与警告）携带：**文件**（宿主可显示的路径，主文件也有）、**行**（出错记号所在行，没有具体记号时是语句首行）、**文案**；若错误归属于某个节点，还带该节点的**路径**；若归属于某条选择器、概念、模式、检查、变体语句，带该语句的种类与首行。文案不必逐字按本规范，但必须包含本规范各处引号里给出的关键信息（例如候选路径列表、允许的取值）。错误按 1.1.5 排序。

### 1.10.2 错误的种类、触发条件与恢复

| 种类 | 触发条件（本章内的例子） | 恢复（1.1.4） |
|---|---|---|
| 语法错误 | 无法识别的字符、缺少结束引号、未知转义、括号不配对、`{` 前缺少语句、缺少 `}`、多余的 `}`、表达式不完整、多余的内容、关键字用错位置、数字格式、方向组合词矛盾、正则不合法、井号记号缺名字 | 整条语句（含块）丢弃；缺少 `}` 时块内语句保留 |
| 未知语句 | 种类词既不是内置种类也不是已定义模板 | 整条语句丢弃 |
| 位置错误 | def / material / import / concept / pattern / check / style / variant 不在最外层；块出现在不接受块的语句上；`use=` 出现在几何时机的 over | 整条语句无效 |
| 名字不合法 | 名字、模板名、let 名、参数名、概念名、模式名、角色名是保留名或关键字；名字不紧跟种类词；copy 没有名字 | 整条语句无效 |
| 未知属性 | 语句种类不接受该属性；模板没有该参数；material 没有该属性；over 对某成员不接受该属性 | 节点退化（over：该成员不被修改） |
| 重复 | 同一语句里重复的属性 / 元数据键 / 标签；同一块里重复的 let；同级重名；def 签名里重复的参数；pattern 重复的角色 | 属性重复：节点退化；同级重名：后出现的语句无效；其余整条语句无效 |
| 缺少必填 | 缺少必填属性（`points`、`path`、`from`、`n`、`of`、mesh 的 `src` / `size`、模板的必填参数）；span 的 `to` / `drop` 都没写 | 节点退化 |
| 互斥 | 多个定位关系；`to` 与 `drop` 同写；`dir` 没有 `drop`；`alignto` 没有 `align`；`aimwith` 没有 `aim`；repeat 的 `along` 与 `step` / `center` 同写、`orient` 没有 `along`（1.4.5、03-solving.md 的 3.8.4）；mirror 的 `across` 是轴名时写了 `axis`（3.9.3）；02-geometry.md 列出的几何互斥 | 节点退化 |
| 类型错误 | 值的种类与属性类型不符；枚举值不合法；布尔不是 true / false；颜色格式；向量长度；算术 / 比较 / 逻辑 / 集合运算的操作数种类不符；函数参数；`where` 条件不是布尔；除以零；结果不是有限数 | 属性值：节点退化；选择器 / 语义语句：该语句无效；let：读到它的地方报错 |
| 找不到的名字 | 名字查找全部失败（1.6.5）；`kind()` 之外的未知名字；路径下降失败且后缀不合法；曲线参数用在非曲线上；未知函数 | 属性值：节点退化；选择器：该语句无效；元数据：该键不存在 |
| 不唯一 | 全局索引里多个同名；穿透得到多个候选 | 同上 |
| 循环 | let / 参数 / 概念循环引用自己；派生链循环；import 循环；copy 循环；定位依赖循环（03-solving.md） | let / 概念：读到它的地方报错；其余：该语句无效或节点退化（各章规定） |
| 时机错误 | 几何时机的选择器用了事实、概念、尺寸字段、锚点 / 度量 / 分量（1.7.4）；属性值或它读到的 `let` 用了关系谓词、概念 / 模式、`where` 里的尺寸字段（1.5.8）；展开时求值的表达式（常量、元数据）用了 `where` / 集合函数 / 对象；被几何时机选择器读到的 `let` 用了上述构件（归属该 `let` 语句，1.5.8） | 该语句无效 / 节点退化 / 该键不存在；let：读它的 over / drop 无效、不另报 |
| 空选择 | over / drop 的选择器为空集（两个时机都报，1.7.1） | 该语句无效 |
| 副本限制 | 对副本式节点写定位属性；对影子换形或改模板参数（04-derivation.md） | 节点退化 / 该 over 对该成员无效 |
| import 错误 | 文件不存在、重复 import、循环、路径不合法、`\` 分隔符 | 不导入 |
| 版本错误 | 文件头 `lang` 不是 2 | 整个文件不编译（只报这一条） |
| 材质错误 | `mat=` 引用未定义的材质；style 的 `mat` 未定义 | 报错；该节点按没有写 `mat` 处理（继承 / 默认 / 内置，10-materials.md），几何不受影响；style 整条无效 |

## 1.11 与原型的差异（供 09-compat.md 汇总）

本章定义的规则与原型（09-compat.md 9.1 指定的 `src/s3d.js`）不同之处，按 9.3 的类别标出：A = 原型不接受、本版合法；B = 原型静默接受、本版报错；C = 两版都接受、结果不同；D = 输出形状不同。原型行为都经读源码并在原型上编译小例子确认（函数名在括号里）。语料（corpus/examples、corpus/exports）没有命中其中任何一项（1.6.9 的两条警告除外）。

| 节 | 情形 | 原型（函数） | 本版 | 类 |
|---|---|---|---|---|
| 1.2.1 | 其他 Unicode 空白（如 U+00A0）出现在属性值里 | `exprTokens` 用 `\s` 当空白跳过 | 报错"无法识别的字符" | B |
| 1.2.1、1.3.3 | 属性值里记号之间有空白（`size=1, 1, 1`、`at=a.top + (0,1,0)`、`on=kind(box) where …`） | `lexStatements` 在深度 0 按空白切词，值被截断（"表达式不完整：1,"、"无法理解 “+”"、"无法理解 “where”"） | 合法：值延伸到第一个不能继续表达式的记号（1.5.1） | A |
| 1.2.3 | `1.`（小数点后没有数字） | 数字正则 `\d+\.?\d*` 接受为 1 | 语法错误 | B |
| 1.2.4 | 单引号字符串 `'x'` | `exprTokens` 接受 `'` 作定界符 | "无法识别的字符" | B |
| 1.2.4 | 转义 `\"`、`\\`、`\n` | 没有转义：`"a\"b"` 在 `\"` 处结束，报"字符串缺少结束引号" | 三种转义合法 | A |

| 1.3.2 | 文件结束时块没有关闭 | 报"缺少 “}”"，行号是文件末行 | 行号是 `{` 所在行 | D |
| 1.3.3 | 名字不紧跟种类词（`box #t a`、`box size=1,1,1 c`） | `makeStmt` 把第一个不是 `k=v`、不以 `#` / `~` 开头的词当名字 | 报错"名字要写在种类词之后" | B |
| 1.3.3、1.9 | 同一语句里重复的属性 / 元数据键 / 标签 | `Map.set` 后写的覆盖先写的；标签数组重复 | 报错"重复的属性 / 元数据 / 标签"，节点退化 | B |

| 1.3.8 | `over a: box`（冒号不带空白） | `makeStmt` 只认独立的 `:` 词，`a:` 交给 `parseValue` 报"无法识别的字符 “:”" | 合法 | A |

| 1.4.2、1.4.3 | 名字字面量类型的值碰巧是某个节点的名字（场景里有节点 `x` 时写 `mirror m of=c across=x`、`cyl … axis=x`） | `evalPath` 先做名字查找：`across=x` 解析成节点 `x`，镜像面过该节点（小例子：副本 t = 15 而不是 −3） | 字面量不做名字查找：`across=x` 是坐标面 | C |
| 1.4.4、3.10.5 | line / bezier / spline 写定位 / 朝向属性；span / sweep / pipe 写 `pin` `mat` `color` 之外的 P 组属性；arc / helix 写 `mat` / `color` | `KIND_PROPS ∪ PLACEMENT` 全部接受，`local` 的 `PATH_CURVES` / `LINKS` 分支不读它们（静默无效） | 报错"X 没有属性 k"，节点退化 | B |

| 1.4.5、3.8.1 | `repeat` 没写 `n` | 缺省 1 个实例（`elaborate`） | 报错"`<路径>` 缺少 n"，节点退化 | B |
| 1.4.5、1.4.3 | span 的 `pin` 不是 `bottom` / `top` / `center` | `Solver.sym` 退回缺省 `center` | 报错"…只能是 bottom / top / center" | B |
| 1.5.1 | 一元 `+`（`size=+2,1,1`） | `unary` 接受并忽略 | 语法错误 | B |
| 1.5.2 | 除以零、结果不是有限数（`1/0`、`sqrt(-1)`） | 得到 Infinity / NaN，节点的盒与位置输出 null，不报错 | 报错"除以零" / "结果不是有限数"，节点退化 | B |
| 1.5.5 | 向量相等 `(1,2) == (1,2)` | `same` 对数组按引用比较，恒为假 | 逐分量比较，为真 | C |

| 1.5.6 | `round` 恰好 .5 | `Math.round`：向 $+\infty$ 取整（$\mathrm{round}(-2.5) = -2$） | 远离零（$-3$） | C |
| 1.5.6 | `kind()`、`min()`、`max()` 没有参数 | `kind()` 得空集；`min()` 得 Infinity | 报错"X() 需要 N 个参数" | B |
| 1.5.8 | 同一块里重复的 `let X` | 后写的覆盖先写的 | 报错"重复定义 X" | B |
